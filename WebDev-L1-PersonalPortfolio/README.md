## 📖 About This Project

For this project, I built a personal portfolio website styled as a dark-themed site with a crimson-rose color scheme, using the **Poppins** font from Google Fonts and **Font Awesome** icons throughout.

It includes a fixed navbar with icon links to each section, a hero section with a circular profile photo, my name, and role title, and an About Me section describing my background as an engineering student at GEC Karwar. The skills section shows a card grid covering HTML5, CSS3, JavaScript, Embedded & IoT, and Git & GitHub.

The projects section features two project cards — a **Flood Alerting System** and a **Low-Cost Monitoring System** — each with an image, description, and GitHub link. The contact section has a form (name, email, message) along with social icons for email, LinkedIn, and GitHub.

## 🎨 Design

- **Font:** Poppins (Google Fonts)
- **Icons:** Font Awesome 6
- **Color theme:** Dark charcoal (`#111827`) + crimson-rose accent (`#f43f5e`)
- **Effects:** Hover animations on cards/buttons, smooth scroll navigation

- **CSS3** — custom properties, grid/flexbox layout, responsiveness
