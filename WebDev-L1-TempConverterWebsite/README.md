## 📖 About This Project

For this project, I built an interactive temperature converter that takes a numeric input in Celsius, Fahrenheit, or Kelvin and instantly converts it into all three units at once. It's styled as a glassmorphic card with a dark gradient background, floating animated glow effects, and Font Awesome icons throughout.

I added input validation so the app rejects empty or non-numeric values and specifically blocks values below absolute zero for whichever unit is selected. Once a valid value is converted, the three result cards animate in with a subtle "pop" effect, and a progress-style temperature meter is shown for visual flair. The whole layout is responsive and adjusts cleanly on smaller screens.

## ✨ Features

| Feature | Details |
|---|---|
| 🔢 Numeric Input | Converts from Celsius, Fahrenheit, or Kelvin |
| 🔄 Simultaneous Output | Shows all three converted units at once |
| 🚫 Input Validation | Rejects empty/non-numeric input with an inline error message |
| ❄️ Absolute Zero Check | Blocks values below -273.15°C / -459.67°F / 0 K |
| 🎬 Result Animation | Result cards "pop" into view after each conversion |
| 🎨 Glassmorphic UI | Blurred glass-style card with animated glow background |
| 📱 Responsive | Adjusts layout for mobile screens |
